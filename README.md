# Пульт охраны банка

Это внутренний репозиторий для сотрудников банка «Сияние». Если вы попали в этот репозиторий случайно, то вы не сможете его запустить, т.к. у вас нет доступа к БД, но можете свободно использовать код вёрстки или посмотреть как реализованы запросы к БД.

Пульт охраны — это сайт, который можно подключить к удалённой базе данных с визитами и карточками пропуска сотрудников нашего банка.
### Как установить

Клонируйте репозиторий:
```
git clone https://github.com/AnhraMainyu-dev/DjangoORM-Lesson
```
Затем используйте `pip` для установки зависимостей:
```
pip install -r requirements.txt
```
Нужно создать файл окружения ****.env**** и в нём следует указать url с настройками подключения к базе данных и свой ключ для шифрования данных в формате:  
```python
DATABASE_URL=postgres://пользователь:пароль@хост:порт/база_данных
SECRET_KEY='REPLACE_ME'
```
Для активации режима разработки следует добавить строку:
```python
DEBUG=True
```

### Использование

Запустите командой `python manage.py runserver` и откройте страницу в браузере по ссылке http://127.0.0.1:8000/
